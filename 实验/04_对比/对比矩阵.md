# 国内外对比矩阵

> 目标：不是"抄一堆数字"，而是**可比性分析**。每个数字后面都必须跟一个括号说明它的实验条件，否则不许写进表里。

## 一、对比维度（列）

| 维度 | 取值示例 |
|---|---|
| 传感模态 | 单目 RGB / RGB-D / 头显自视角 / IMU 腕带 / 指环 / 超声 |
| 机位 | 前置 / 俯拍桌面 / 头戴 / 无相机 |
| 触发方式 | 捏合 pinch / 悬停 dwell / 空中点击 air-tap / 手指下压 push / 深度 z / 压力 |
| 是否需标定 | 需要（单应/平面标定） / 免标定 |
| 键盘形态 | 空中虚拟键盘 / 平面投影键盘 / 实体键盘 / 无键盘（手势编码） |
| 硬件成本 | 低（普通摄像头）/ 中（RGB-D、腕带）/ 高（头显、投影仪） |
| 报告速度 (wpm) | 数字 + 条件 |
| 报告错误率 | CER / NCER / UER / TER + 定义 |
| 被试数 / 条件数 | 例：n=18, 3 条件 |
| 主要局限 | 自遮挡 / 光照 / 无触觉 / 需重训模型 |

## 三、可比性分级（必须标在每行末尾）

| 等级 | 含义 | 处理方式 |
|---|---|---|
| A 可直接比 | 同为单目 RGB、逐键输入、同一短语集 | 放主表，参与排名 |
| B 需换算 | 只报了 CER 没报 UER；或短语集不同 | 标注换算方式与不确定性 |
| C 不可比 | 用了 RGB-D / 头显 / IMU / 语言模型 | 单列为"参考上限"，并写明差在哪 |

## 四、每篇文献要抄下来的字段（提取清单）

- [ ] 全名 + venue + 年份 + DOI/URL（**自己打开过**才算）
- [ ] 传感模态与机位（决定可比性）
- [ ] 触发方式、是否需要标定
- [ ] 速度与错误率的**定义**（wpm 是否减 1？错误率是 CER 还是 UER？）
- [ ] 被试数、条件数、训练时长
- [ ] 是否用了语言模型/概率解码（这是最大的"不可比"因素）
- [ ] 论文自己承认的局限（写进"主要局限"列）

## 五、结论段模板（半页，答辩用）

> 在 10 篇代表性工作中，**纯空中虚拟键盘**的公开成绩集中在 ______ wpm / ______% 错误率区间；把键盘"落到某个平面"并叠加**概率解码 + 语言模型**后可达 ______ wpm。我们属于**单目 RGB、免标定、无语言模型**的最朴素一档，实测 ______ wpm / NCER ______%，与该档位的区间一致。
> 差距的两个可解释来源是：①没有接触面锚定与触觉反馈；②没有用语言模型纠正视觉误差。两者都不属于识别算法的缺陷，且都在本项目的成本约束（普通 USB 摄像头）之内。
> 若继续优化，性价比最高的两步是 ______ 和 ______（例如：引入标准短语集下的 n-gram 后处理、加入第二视角缓解自遮挡）。

## 六、纪律（避免被指出"二手数据"）

1. **不引用二手转述的数字**：每个数都要在原文里找到（表格/摘要/结果章节），并记下页码或小节
2. 同一篇论文有多个实验时，**只取与你条件最接近的那一组**，并注明
3. 允许"没有可比数据"的格子写 `—`，并说明原因
4. 两个人各查一遍，结果不一致的格子标 `⚠` 并回原文核对（写进 `文献检索记录.md`）
