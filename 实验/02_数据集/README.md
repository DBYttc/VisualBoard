# 自评数据集（采集协议）

## 一、这是什么数据（先跟老师对齐口径）

- MediaPipe 的检测模型是**预训练**的，我们不训练它。
- 这里采集的是**带真值的"手势按键"评测数据集**：用固定短语让被试输入，于是"应该出哪些键"是已知的 → 可算检出率、误触率、延迟。
- 这些数据同时也能用于**将来训练一个轻量分类器**（例如"按下/悬停"二分类），但当前阶段只做评测，不做训练。

## 二、采集因素（每个因素 2~3 档）

| 因素 | 档位 | 为什么要这个因素 |
|---|---|---|
| 光照 | ① 顶灯 ② 顶灯 + 补光灯 ③ 仅屏幕光 | 光照是这类系统最大的不稳定源 |
| 摄像头高度 | 35 / 45 / 55 cm（桌面贴胶带标记） | 影响表观尺寸与触发阈值 |
| 桌面背景 | 木桌 / 铺白纸 | 影响 mask 类信号与视觉对比度 |
| 被试 | ≥ 5 人（手型差异大一点） | 避免"只对一个人有效" |
| 手表/戒指 | 有 / 无 | 真实的干扰源 |

**最小可行规模**：3 个条件 × 5 人 × 2 次重复 = **30 段**，每段 20~30 秒。

## 三、目录与命名

```
实验/02_数据集/raw/
└── S01_王小明/
    ├── L1_H45_M/                     ← 光照1 / 高度45 / 木桌
    │   ├── S01_L1_H45_M_01.mp4       ← 00:00 起全程录屏（含 HUD）
    │   └── S01_L1_H45_M_01.csv       ← 该段元数据（可从 采集清单.csv 摘）
    └── L2_H45_M/
```
- 命名规则：`被试_光照_高度_背景_序号`
- **录屏必须包含程序窗口**（有 HUD 的 `x` 值和按键闪烁），否则无法标注
- 原始视频放 `raw/`（`*.mp4` 已在 .gitignore，不会进仓库；交材料时单独拷 U 盘/网盘）

## 四、采集步骤（每次照做）

1. **试拍 3 段**：检查 ① 手是否完整在画面内 ② 键盘是否铺满且贴底 ③ 帧率（HUD 的 FPS）是否 ≥ 20 ④ 是否有反光/过曝
2. 打开录屏（全屏，60fps），启动程序，**按 R 重新标定**，等 `CALIBRATING` 结束
3. 朗读提示（用 `实验流程口语稿.md`），然后按固定短语输入；**每段开始前静置 3 秒**（便于对齐时间轴）
4. 输入过程中**故意做 1~2 次"悬停但不按"**（用于统计误触基线）
5. 结束后停止录屏，立刻在 `采集清单.csv` 登记一行
6. 换条件前**重新标定**（换高度/光照后必须）

## 五、标注规范（填 `标注模板.csv`）

| 字段 | 取值 | 说明 |
|---|---|---|
| `素材ID` | 如 `S01_L1_H45_M_01` | 与文件名一致 |
| `帧起` / `帧止` | 整数帧号 | 用播放器逐帧（左右键）读 |
| `状态` | `hover` / `press` / `false_trigger` / `missed` | 见下 |
| `手指` | thumb/index/middle/ring/pinky 或空 | 只有 press/false_trigger 需要 |
| `目标键` | 如 `k` / `space` / `enter` | 该段应输出的键 |
| `实际出字` | 实际屏幕上出现的字符（含空格） | 用于算准确率 |
| `备注` | 一句话 | 例如"这一段手抬太高" |

**状态怎么判**（不需要写代码，看画面对照）：

- `press`：HUD 的 `x` 越过 `enter_ratio` 并且屏幕上确实出现了字符
- `false_trigger`：`x` 越过了阈值、但**当时并不想按**（手指路过/抖动）
- `missed`：明明下压了（能看出动作），但**没有出字**
- `hover`：其余时间（手指在键盘上但未触发）

**标注粒度**：不需要每帧都标，只标"状态发生变化"的区间（30 秒一段通常 20~40 行）。

## 六、训练/验证/测试怎么划分（老师可能会问）

**按被试划分**（subject-independent）：S01–S03 训练、S04 验证、S05 测试。
不要按帧随机分——同一个人同一段视频会同时出现在训练和测试里，指标会虚高。

## 七、质检清单（每段素材打勾）

- [ ] 手完整在画面内，没有被画面边缘裁掉
- [ ] HUD 可见（FPS、`depth(...)` 的 x 值、按键闪烁）
- [ ] FPS ≥ 20（低于 15 的段作废）
- [ ] 无严重过曝/欠曝（能看清手指轮廓）
- [ ] 摄像头没有被碰到（画面构图与上一段一致）
- [ ] 标定已完成（画面上没有 `CALIBRATING`）
- [ ] 已登记 `采集清单.csv` 一行

## 八、隐私与伦理

- 只采**手部与桌面**：录屏后可用播放器裁掉包含人脸/房间的部分再归档
- 每位被试先签 `被试知情同意书.md`（说明用途、保存期限、可随时退出并删除）
- 被试姓名只写代号（S01…），姓名与代号对应表单独存、不进仓库
