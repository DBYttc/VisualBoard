# 实验记录（调参 / 自评数据集 / 国内外对比）

本目录是**过程性证据**：老师要看的不是结论，而是"你试了什么、怎么记的、为什么这样定"。
所有文件都能用 Excel / VS Code / 记事本直接打开填写，**不需要改动任何程序代码**。

## 三份交付物

| # | 交付物 | 在哪 | 完成标准 |
|---|---|---|---|
| 1 | 调参记录 | `01_调参/` | ≥ 9 组参数（3 组实验 × 3 档），每组 3 次重复，含失败记录；最终值有"依据"一栏 |
| 2 | 自评数据集 | `02_数据集/` | ≥ 30 段素材（5 人 × 3 条件 × 2 重复），全部登记在 `采集清单.csv`，≥ 10 段完成帧级标注 |
| 3 | 国内外对比 | `04_对比/` | 对比矩阵 ≥ 10 篇文献 + 我们的系统；每个数字带"条件括号"；有"差距归因"结论 |

## 怎么跑一次并留下日志（不改程序）

```powershell
cd D:\VisualBoard
$env:PYTHONUNBUFFERED="1"
.\.venv\Scripts\python.exe -m visualboard.app.main 2>&1 |
  Tee-Object -FilePath "实验\05_日志\run_$(Get-Date -Format yyyyMMdd_HHmm)_enter110.txt"
```

跑完在 Excel 里数 `Emitted key=` 的行数 = 实际触发次数；对照你输入的目标短语即可算准确率。

## 两个容易忽略的坑

1. **CSV 是 UTF-8 带 BOM**：Excel 双击不乱码；用 Python 读请 `encoding="utf-8-sig"`。
2. **每次改参数前先另存快照**（`参数快照_20261021_enter108.md`）。否则事后没人知道那 9 行数据是在什么参数下跑出来的，整张表就作废了。
