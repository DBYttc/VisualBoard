# 参数快照（基线）

- 快照时间：2026-10-20
- 采集方式：从程序实际加载后的配置导出（不是抄 YAML，避免漏掉 local 覆盖）
- 用途：**每次调参前另存一份**，命名 `参数快照_YYYYMMDD_<说明>.md`，并在 `调参记录表.csv` 的"参数快照"列填文件名

## 一、生效参数

### 摄像头

| 参数 | 值 | 含义 |
|---|---|---|
| `camera.device_index` | 0 | 使用的摄像头索引 |
| `camera.width` / `height` | 1280 / 720 | 工作分辨率（画布会按实际输出等比调整） |
| `camera.mirror` | False | 是否左右镜像（俯视机位通常关闭） |
| `camera.backend` | auto | 先试 DSHOW，失败退回系统默认 |
| `camera.capture` | native | 不切分辨率采集，`read()` 内等比缩放 |

### 手部检测

| 参数 | 值 |
|---|---|
| `mediapipe.max_num_hands` | 1 |
| `mediapipe.min_detection_confidence` | 0.75 |
| `mediapipe.min_tracking_confidence` | 0.75 |
| `mediapipe.model_complexity` | 1 |

### 按下判定（核心）

| 参数 | 值 | 含义 |
|---|---|---|
| `depth_press.enabled` | True | 是否启用表观尺寸触发 |
| `depth_press.source` | finger_length | 信号源：五指 MCP→TIP 投影长度 |
| `depth_press.direction` | far | 投影变短 = 按下 |
| `depth_press.baseline_mode` | startup | 启动标定一次并冻结基准 |
| `depth_press.warmup_sec` | 3.0 | 标定窗口（秒） |
| `depth_press.enter_ratio` | **1.10** | 变化 ≥10% 进入 |
| `depth_press.exit_ratio` | **1.06** | 回到 ≤6% 退出（迟滞） |
| `depth_press.stable_frames` | **2** | 检测器连续确认帧数 |
| `depth_press.baseline_samples` | 45 | 基准取最近 N 帧中位数 |
| `depth_press.min_samples` | 15 | 基准最少样本数 |
| `depth_press.latch_key` | True | 按下瞬间锁定键位（抗视差） |
| `interaction.pinch_source` | depth | 触发来源：深度（五路并行） |
| `interaction.pinch_fire_on` | press_edge | 一次按压只出一次 |
| `interaction.pinch_stable_frames` | **3** | 状态机连续确认帧数 |
| `interaction.cooldown_sec` | 0.4 | 全局冷却 |

### 指针平滑 / 界面

| 参数 | 值 |
|---|---|
| `smoothing.ema_alpha` | 0.3 |
| `ui.canvas_width` / `height` | 1280 / 720（实际画布跟随摄像头输出） |
| `ui.keyboard_margin` / `keyboard_bottom` | 0 / 20 |
| `ui.key_gap` / `row_gap` | 6 / 8 |
| `ui.key_aspect` | 1.0 |
| `ui.keyboard_opacity` | 0.5 |

## 二、如何重新生成这份快照

```powershell
cd D:\VisualBoard
.\.venv\Scripts\python.exe -c @"
import dataclasses
from visualboard.core.config_loader import load_settings
def dump(obj, prefix=''):
    for f in dataclasses.fields(obj):
        v = getattr(obj, f.name)
        if dataclasses.is_dataclass(v): dump(v, prefix + f.name + '.')
        else: print(f'{prefix}{f.name} = {v}')
dump(load_settings())
"
```
