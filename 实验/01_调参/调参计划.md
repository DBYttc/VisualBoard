# 调参计划（三组单因素实验）

> 原则：**一次只改一个参数**、**每组 3 次重复**、**每次运行前重新标定**、**每次运行都留日志与快照**。
> 所有实验都在同一台机器、同一机位、同一测试短语下进行；换条件必须记录。

## 0. 固定条件（写在每行记录里）

| 项 | 取值 |
|---|---|
| 机位 | 摄像头俯拍，高度 ______ cm（用胶带在桌上做标记，保证每次一致） |
| 光照 | ______（顶灯 / 顶灯+补光灯 / 仅屏幕光） |
| 桌面 | ______（木桌 / 铺白纸） |
| 测试短语 | `the quick brown fox jumps`（25 字符，含空格；每次相同） |
| 操作者 | ______（同一人做同一组实验，换人要记录） |
| 标定动作 | 启动后 3 秒内把手摆到"自然悬停"姿势，不动 |

## 实验 A：进入 / 退出阈值（决定"多小的动作算按下"）

| 档 | `enter_ratio` | `exit_ratio` | 其余参数 |
|---|---|---|---|
| A1 | 1.06 | 1.02 | 与基线快照一致 |
| A2 | **1.10（基线）** | 1.06 | 同上 |
| A3 | 1.14 | 1.10 | 同上 |

- 自变量：阈值档位；因变量：成功触发率、误触率（次/分钟）、漏触率、平均延迟
- 重复：每档 3 次（每次输入同一短语一遍 + 30 秒自由悬停用于统计误触）
- 判定：**先满足「成功触发率 ≥ 90% 且 误触 ≤ 1 次/分钟」，再在满足者中取延迟最小**
- 画图：横轴 `enter_ratio`，左纵轴成功触发率、右纵轴误触率（Excel 双轴折线即可）

## 实验 B：确认帧数与冷却（决定"延迟 vs 抗噪"）

| 子实验 | 参数 | 档位 | 观测 |
|---|---|---|---|
| B1 | `depth_press.stable_frames` | 2 / 3 / 5 | 延迟、误触率 |
| B2 | `interaction.pinch_stable_frames` | 2 / 3 / 4 | 延迟、误触率 |
| B3 | `interaction.cooldown_sec` | 0.2 / 0.3 / 0.4 | 连续 10 键耗时、被吞键数 |

- **延迟怎么测**：录屏（60fps），数"HUD 上 x 第一次越过阈值"到"目标程序出现字符"的帧数 ÷ 60
- **注意**：两级确认是叠加的（检测器 N 帧 + 状态机 M 帧），报告时写"总延迟 ≈ (N+M) 帧 × 33ms + 35ms"
- 判定：误触率相同的档位里取延迟最小；B3 取"不吞键的最大速度"

## 实验 C：信号源（决定"用什么量判断距离"）

| 档 | `depth_press.source` | 特点 |
|---|---|---|
| C1 | **finger_length（基线）** | 五指投影长度，纯关键点，不吃光照 |
| C2 | `mask` | 肤色分割量指节宽度，依赖光照/肤色 |
| C3 | `hand_scale` | 手腕→中指根，整手上下移动敏感 |

- 每档在**三种光照**下各跑一次（3 × 3 = 9 次），记录"能否稳定得到信号"
- 因变量：检出率、误触率、信号丢失次数（HUD 显示 `n/a` 的次数）
- 判定：优先选"三种光照下都能用"的源；若 `mask` 只在补光下可用，就把它写成"受限条件下的备选"

## 记录规范

1. **一行 = 一次运行**，参数列必须和当时的 `参数快照_*.md` 完全一致
2. 每次启动后**先按 R 重新标定**再开始测（否则基准来自上一次的姿势）
3. 失败也要写（"这一档按不出来"也是结论），并在"结论"列写清原因
4. 日志文件名带参数：`run_20261021_1050_A2_enter110.txt`

## 结论怎么写（每组三句话）

> 在 ______ 条件下，把 `enter_ratio` 从 1.06 提到 1.14，成功触发率由 __% 变为 __%，误触率由 __ 次/分 变为 __ 次/分，平均延迟由 __ms 变为 __ms。
> 因此选 ______ 作为最终值，依据是 ______。
> 该结论的适用范围是 ______（光照/高度/操作者），超出范围需要重新标定。

## 常见错误（自查用）

- [ ] 同一行混用了两次不同的参数（作废）
- [ ] 每组只跑 1 次就下结论（噪声会被当成效应）
- [ ] 改了 `source` 却没重标定（基准含义变了）
- [ ] 用不同短语做的两组数据直接比 wpm（不可比）
- [ ] 忘了记录光照/高度，导致复现不了
- [ ] 只记录"成功的那几次"
